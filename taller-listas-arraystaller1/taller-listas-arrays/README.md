# Taller de laboratorio: listas y arrays

## Descripción
Proyecto en Python para comparar el rendimiento de una lista nativa y un array de NumPy, y practicar el procesamiento de calificaciones de estudiantes.

## Requisitos
- Python 3
- NumPy

## Instalación de NumPy
Abre una terminal y ejecuta:

```bash
python -m pip install numpy
```

## Cómo ejecutar los programas
Desde la carpeta principal del proyecto:

```bash
python comparacion.py
python parte2/calificaciones.py
```

## Archivos del proyecto
- `comparacion.py`: compara el tiempo de multiplicar 100.000 números por dos con una lista y un array.
- `parte2/calificaciones.py`: calcula promedio, cuenta aprobados y reprobados y aplica una regla ilustrativa a las notas inferiores a 3.0.
- `informe.md`: explica el experimento y presenta el análisis.
- `evidencias/`: capturas de pantalla aportadas para documentar el trabajo.
